# TREASURE DASH V4 — Server Relay (Free starter)

เวอร์ชันนี้ใช้ WebSocket Server กลาง และให้เซิร์ฟเวอร์ควบคุมห้อง ผู้เล่น การแจกการ์ด เทิร์น ผลการ์ด และเวลา

## โครงสร้างไฟล์
- `public/index.html` — เกม Premium
- `server.js` — เว็บเซิร์ฟเวอร์และระบบเกมออนไลน์
- `package.json` — dependencies และคำสั่งเริ่มระบบ
- `render.yaml` — ตัวอย่างการตั้งค่า Render

## วิธีติดตั้งฟรีบน Render
1. แตกไฟล์ ZIP บนคอมพิวเตอร์
2. สร้าง GitHub repository ใหม่ แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดตามโครงสร้างเดิม
3. เข้า Render แล้วเลือก New > Web Service
4. เชื่อม GitHub repository นี้
5. ตั้ง Build Command เป็น `npm install`
6. ตั้ง Start Command เป็น `npm start`
7. เลือก Free plan แล้วกด Deploy
8. เมื่อสำเร็จ เปิด URL ของ Render เช่น `https://ชื่อบริการ.onrender.com`

หน้าเกมและ WebSocket จะอยู่บนโดเมนเดียวกัน ระบบจะเลือก `wss://` ให้อัตโนมัติเมื่อเปิดผ่าน HTTPS ไม่จำเป็นต้องกรอก URL เซิร์ฟเวอร์ในหน้าเกม หากใช้ URL นี้โดยตรง

## หากต้องการใช้หน้าเกมจาก ship.page เดิม
เปิดหน้าเกม V4 แล้วกรอก `wss://ชื่อบริการ.onrender.com` ในช่อง “ที่อยู่เซิร์ฟเวอร์เกม” จากนั้นกดบันทึกเซิร์ฟเวอร์ แต่แนะนำให้ใช้ URL Render เดียวกันทั้งหน้าเกมและเซิร์ฟเวอร์เพื่อลดการตั้งค่าผิด

## วิธีทดสอบ
1. เปิด URL Render บนเครื่อง Host
2. เปิด URL เดียวกันบนมือถือเพื่อน โดยใช้คนละเครือข่าย (เช่น Wi-Fi กับเน็ตมือถือ)
3. Host กดสร้างห้อง ส่งรหัส 6 ตัวให้เพื่อน
4. เพื่อนใส่รหัสแล้วกดเข้าห้อง
5. เมื่อมี 2–4 คน Host กดเริ่มเกม
6. เล่นการ์ดสลับเทิร์น ตรวจคะแนนและตัวจับเวลา

## ข้อจำกัด Free plan
- เซิร์ฟเวอร์ฟรีอาจพักเมื่อไม่มีการใช้งาน การเข้าเว็บครั้งแรกหลังพักอาจต้องรอให้บริการเริ่มทำงาน
- หากเซิร์ฟเวอร์รีสตาร์ต ห้องที่กำลังเล่นจะหายไป
- ยังไม่มีระบบบัญชีผู้ใช้หรือการกลับเข้าห้องหลังเน็ตหลุด
- ต้อง Deploy ด้วยบัญชี Render/GitHub ของคุณเองก่อนจึงจะมี URL เล่นจริง ไฟล์ที่แนบมายังไม่ได้ถูกเผยแพร่

## ความถูกต้องของเกม
เซิร์ฟเวอร์สุ่มและเก็บการ์ดในมือ ตรวจสอบว่าเป็นเทิร์นของผู้เล่นก่อนใช้การ์ด และคำนวณผลคะแนนบนเซิร์ฟเวอร์ เบราว์เซอร์ส่งเพียงคำสั่งเล่นและตำแหน่งการ์ด
