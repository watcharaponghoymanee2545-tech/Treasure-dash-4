# TREASURE DASH — Server Relay (2–6 คน / ไม่มีตัวจับเวลา)

เกมการ์ดออนไลน์แบบผลัดเทิร์น ใช้ WebSocket Server กลางควบคุมห้อง การแจกการ์ด เทิร์น และผลของสกิล

## กติกาหลัก
- รองรับผู้เล่น 2–6 คนต่อห้อง
- ไม่มีตัวจับเวลา
- ผู้เล่นแต่ละคนได้รับการ์ดสุ่ม 3 ใบ และเลือกใช้ 1 ใบในเทิร์นของตน
- เกมจบเมื่อผู้เล่นคนใดคนหนึ่งมีแต้มดวงถึง 15 แต้ม
- แต้มดวงไม่ต่ำกว่า 0
- โล่ป้องกันการโจมตีได้ 1 ครั้ง ยกเว้นการ์ดตบพวกติ๋มที่ทะลุและทำลายโล่
- เมื่อใช้บ่าวเทียร์ S เทิร์นถัดไปจะถูกข้าม ผู้เล่นสามารถใช้ Negate! เพื่อยกเลิกสถานะข้ามเทิร์นแทนการเสียเทิร์นได้

## การ์ดทั้ง 15 ใบ
1. 🏅 เด็คกูเทียร์ B — รับ 2 แต้ม
2. 🧂 กูเกลือ — สุ่มผู้เล่น 1 คน แล้วสุ่ม +2 หรือ -2 แต้ม
3. 🧲 ตูนดูดดวงง — รับ 1 แต้ม และชิง 1 แต้มจากผู้เล่นที่นำอยู่
4. 🥷 บิด — ชิง 1 แต้มจากผู้เล่นที่นำอยู่
5. 🥽 กูติ๋ม — รับ 1 แต้ม และโล่ 1 ครั้ง
6. 🎰 Gacha Time! — สุ่มรับ 0–3 แต้ม
7. 👊 ตบพวกติ๋ม — สุ่มแย่ง 1 แต้ม หากเป้าหมายมีโล่ แย่ง 2 แต้มและทำลายโล่
8. 💸 ยืมตังหน่อยย — ผู้เล่นที่นำอยู่เสีย 1 แต้ม คุณได้รับ 1 แต้ม
9. 🪙 โปรยเศษเงิน — สุ่มรับ 2–3 แต้ม ผู้เล่นอื่นทุกคนได้คนละ 1 แต้ม
10. 🚫 Negate! — รับ 1 แต้ม และล้างสถานะข้ามเทิร์นของตัวเอง
11. 💦 สาดไปสมาชิก — ผู้เล่นอื่นทุกคนเสียคนละ 1 แต้ม
12. 🥀 กูจน — รับ 2 แต้ม ถ้าอยู่อันดับท้ายรับเพิ่ม 1 แต้ม
13. 🤑 พวกบ้านรวย — ผู้เล่นที่มีแต้มมากกว่าคุณเสียคนละ 1 แต้ม คุณรับ 1 แต้ม
14. 🪞 Mirror Force — สุ่มลบ 1 แต้มจากผู้เล่นอื่น และได้รับโล่ 1 ครั้ง
15. 👑 บ่าวเทียร์ S — รับ 3 แต้ม แต่ข้ามเทิร์นถัดไป

## การอัปเดตบน Render
1. แทนที่ `server.js` และ `public/index.html` ใน GitHub ด้วยไฟล์จาก ZIP นี้
2. Commit changes แล้วรอ Render deploy จนสถานะ Live
3. รีโหลดหน้าเว็บเกม (หากหน้าเก่ายังค้าง ให้รีเฟรชแบบล้างแคช)

- หากเจ้าของห้องออก ห้องจะถูกปิด
